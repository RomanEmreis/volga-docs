# volga-docs

The documentation site for the Volga web framework (VuePress 2, `docs/en` and `docs/ru`) and its Agent Skill (`skill/volga`).

Before changing anything here, read and follow:

- @CONTRIBUTING.md for where a change goes, the version rules, snippets, both locales and the release checklist.
- @TRANSLATING.md for any text in `docs/ru`.

Run the checks listed in CONTRIBUTING.md before you open a pull request. When asked to update the docs for a new Volga release, follow "When Volga releases" in CONTRIBUTING.md step by step.

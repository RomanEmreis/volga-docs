# Туториал: сервис закладок

В этом туториале строится небольшой, но законченный JSON API: сервис, который хранит закладки. Каждая глава добавляет к одной и той же программе ещё один слой и заканчивается полным `src/main.rs` в его текущем виде, так что после любой главы у вас есть работающий сервер.

Туториал написан для разработчиков, которые уже делали HTTP-сервисы на C#, Java, Go или чём-то ещё и впервые видят Волгу. Сам Rust он не объясняет: где коду нужна возможность языка, текст называет её и даёт ссылку на [Rust Book](https://doc.rust-lang.org/book/). Если термин Волги незнаком, страница [Если вы пришли с ASP.NET Core, Spring или Go](/volga-docs/ru/getting-started/coming-from.html) сопоставит его с тем, который вы знаете.

## Что получится

| Метод и путь | Что делает | Кому доступен |
|---|---|---|
| `POST /login` | Обменивает имя пользователя и пароль на токен | всем |
| `GET /bookmarks` | Возвращает список закладок, `?tag=rust` фильтрует его | всем |
| `GET /bookmarks/{id}` | Возвращает одну закладку | всем |
| `POST /bookmarks` | Сохраняет закладку от имени вызывающего | вошедшему пользователю |
| `DELETE /bookmarks/{id}` | Удаляет закладку | её владельцу или администратору |

По ходу дела сервис получает то, что нужно настоящему API:

1. **[Проект и первые маршруты](/volga-docs/ru/tutorial/first-routes.html):** проект, маршруты, JSON на входе и выходе и хранилище, общее через внедрение зависимостей.
2. **[Валидация и ошибки](/volga-docs/ru/tutorial/validation-errors.html):** правила для входящих закладок, собственный тип ошибки и ответ на любую ошибку в формате [Problem Details](https://www.rfc-editor.org/rfc/rfc9457).
3. **[Аутентификация](/volga-docs/ru/tutorial/authentication.html):** JWT-токены, маршруты только для вошедших пользователей и проверка, что пользователь удаляет только свои закладки.
4. **[Тестирование](/volga-docs/ru/tutorial/testing.html):** интеграционные тесты, которые запускают сервис и отправляют ему настоящие запросы.

## Перед началом

* **Rust 1.90 или новее.** Установите его через [rustup](https://rustup.rs/) или выполните `rustup update`, если Rust уже установлен.
* **curl** или любой другой HTTP-клиент, чтобы вызывать сервис вручную.

Хранилище держит закладки в памяти, поэтому после остановки сервера они пропадают. Так туториал остаётся про Волгу, а не про базу данных; в последней главе сказано, где появилась бы настоящая.

Начните с главы [Проект и первые маршруты](/volga-docs/ru/tutorial/first-routes.html).
